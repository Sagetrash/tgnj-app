# Global Coding Style Preferences

## General Guidelines
- **Language Stack**: TypeScript/Node.js, Python 3 for automation, Vanilla CSS for web UI.
- **Git Etiquette**: Conventional commits (`feat`, `docs`, `fix`, `chore`), clean feature branching, atomic commits.
- **Dependency Philosophy**: Prefer stdlib or zero-dependency solutions for scripts where possible.
